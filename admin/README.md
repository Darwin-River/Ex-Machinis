# Admin

Tools and notes for the people who run and maintain the game.

- [announce.py](announce.py): posts new strategy blog posts to Bluesky and Mastodon; run by the **Announce blog posts** Action (see the [sustainability playbook](../documents/sustainability-playbook.md#posting-automatically)).
- [db_backups.md](db_backups.md): backing up game data (the current process is in [hosting.md](../documents/hosting.md#back-up-the-game)).
- [analytics.md](analytics.md): tagging links in posts so visits can be counted.
