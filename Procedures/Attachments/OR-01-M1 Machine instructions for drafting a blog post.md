# OR-01-M1: Machine instructions for drafting a blog post

1. <a id="1"></a>Always review and follow the most recent version of these instructions.

2. <a id="2"></a>Scope

   1. <a id="2.1"></a>Apply these instructions when directed to draft a post for the Ex Machinis blog.

3. <a id="3"></a>Drafting the post

   1. <a id="3.1"></a>Read the post's issue, the three most recent posts in `documents/blog/`, and the docs and pull requests the post is about.

   2. <a id="3.2"></a>Copy the "Blog post template" ([OR-01-T1](OR-01-T1%20Blog%20post%20template.md)) to `documents/blog/` under the next number and a short slug.

   3. <a id="3.3"></a>Write to the guidelines in [OR-01](../SOPs/OR-01%20Writing%20and%20publishing%20blog%20posts.md) §4: one idea, plain words, a working Lua example, and something to try at the end.

   4. <a id="3.4"></a>Run every Lua example against a local world, or say in the pull request which examples you could not run.

   5. <a id="3.5"></a>Check every function name against `documents/lua-functions.md` and every number against the code or the round it came from.

   6. <a id="3.6"></a>Open the pull request per [AD-02](../SOPs/AD-02%20Working%20with%20branches%20and%20pull%20requests.md). In it, suggest one or two social posts to announce it, per the "Social media post template" ([OR-02-T1](OR-02-T1%20Social%20media%20post%20template.md)).

4. <a id="4"></a>Provide a concise summary of activities performed and issues encountered when performing these instructions, including the post's address once merged and which examples were tested.
