# OR-03-A1: Audiences and messages

1. <a id="1"></a>What Ex Machinis offers learners

   1. <a id="1.1"></a>**A real language.** Drones are programmed in Lua, a small, readable language used in games and embedded systems.

   2. <a id="1.2"></a>**Fast, visible feedback.** A game day passes in under a minute. Release a drone, watch it work or fail on its page, fix it, release again: break, learn, repeat.

   3. <a id="1.3"></a>**Failure is free.** Every release is live and costs nothing, so trying is never punished.

   4. <a id="1.4"></a>**Something worth programming.** Drones mine, refine, trade and travel through our real solar system, so students practise logic, data and simple economics together.

   5. <a id="1.5"></a>**No barriers.** It runs in a browser, needs no installs and no accounts, collects no personal data, and is free.

   6. <a id="1.6"></a>**Open.** The code, the docs and these SOPs are public on GitHub, so advanced students can see how a real project is built and run.

2. <a id="2"></a>Audiences

   1. <a id="2.1"></a>**High school students** (about 14 to 18). Need: a quick first win, clear errors, and goals they choose. Message: "Program a spacecraft. Watch it fly. Make it better."

   2. <a id="2.2"></a>**High school teachers** of computer science, technology, robotics or maths, including teachers new to programming. Need: ready-to-run lessons that fit a class period, that map to their course, and that need no setup or student data. Message: "A free, browser-based coding lab with lessons ready for Monday."

   3. <a id="2.3"></a>**Coding and robotics clubs** and after-school programs. Need: open-ended challenges and friendly competition. Message: "Set your club a challenge: whose drones earn the most by Friday?"

   4. <a id="2.4"></a>**Parents and home learners.** Need: something safe and free their teenager can explore alone. Message: "Learn to code by doing, safely and for free."

   5. <a id="2.5"></a>**Adult learners and hobbyists** in the general public. Need: a reason to practise programming that is more fun than exercises. Message: "Learn to code by running a space company."

   6. <a id="2.6"></a>**Supporters and sponsors** who care about education. Need: to see that their money reaches learners. Message: "Help keep a coding classroom free for every student," per [FR-01](../SOPs/FR-01%20Raising%20funds%20through%20Ko-fi.md).

3. <a id="3"></a>Keep this list current, per [OR-03](../SOPs/OR-03%20Promoting%20Ex%20Machinis%20to%20schools%20and%20learners.md) §5.1. Change a message when a teacher, student or playtest shows it is not landing.
