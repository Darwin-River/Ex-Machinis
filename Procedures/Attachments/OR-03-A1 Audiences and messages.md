# OR-03-A1: Audiences and messages

1. <a id="1"></a>What Ex Machinis offers learners

   1. <a id="1.1"></a>**A real language.** Drones are programmed in Lua, a small, readable language used in games and embedded systems. A drone is a Lua program with a `launched()` function; once released, it runs on its own and cannot be steered.

   2. <a id="1.2"></a>**Fast, visible feedback.** A game day passes in under a minute. Release a script, watch the drone work or fail on its public page (where it is, what it carries, what it did and what it says), fix it, release again: break, learn, repeat.

   3. <a id="1.3"></a>**Failure is free.** Every release is live and costs nothing, and each one founds a new company, so trying is never punished. There is no test world.

   4. <a id="1.4"></a>**Something worth programming.** Drones mine, refine, manufacture, trade at the exchanges, talk to other drones, and build and launch copies of themselves across our real solar system, in a world every player shares. Students practise loops, state machines, functions, data and handling what goes wrong, with some simple economics along the way.

   5. <a id="1.5"></a>**No barriers.** Students write and release a script on the website's **Release** page, starting from a starter script. No installs, no accounts, no personal details, and nothing to buy.

   6. <a id="1.6"></a>**Open.** The code, the docs and these SOPs are public on GitHub under the MIT licence, so advanced students can see how a real project is built and run, and contribute to it per `CONTRIBUTING.md`.

   7. <a id="1.7"></a>**Room to grow.** The leaderboard ranks companies by net wealth, and the API lets experienced coders and AI agents play from a program under the same rules: an approachable first project, and a hard optimisation problem.

2. <a id="2"></a>Audiences

   1. <a id="2.1"></a>**High school students** (about 14 to 18). Need: a quick first win, clear errors, and goals they choose. Message: "Program a spacecraft. Watch it fly. Make it better."

   2. <a id="2.2"></a>**High school teachers** of computer science, technology, robotics or maths, including teachers new to programming. Need: ready-to-run lessons that fit a class period, that map to their course, and that need no setup or student data. Message: "A free, browser-based coding lab with lessons ready for Monday."

   3. <a id="2.3"></a>**Coding and robotics clubs** and after-school programs. Need: open-ended challenges and friendly competition. Message: "Set your club a challenge: whose drones earn the most by Friday?"

   4. <a id="2.4"></a>**Parents and home learners.** Need: something safe and free their teenager can explore alone. Message: "Learn to code by doing, safely and for free."

   5. <a id="2.5"></a>**Adult learners and hobbyists** in the general public. Need: a reason to practise programming that is more fun than exercises. Message: "Learn to code by running a space company."

   6. <a id="2.6"></a>**Supporters** who care about education. Need: to see what their support pays for: the server, the domain and the AI subscription, and nothing more. Message: "Chip in to keep the lights on, so the game stays free for every student," per [FR-01](../SOPs/FR-01%20Raising%20funds%20through%20Ko-fi.md).
