# DV-02-M1: Machine instructions for running a playtest round

1. <a id="1"></a>Always review and follow the most recent version of these instructions.

2. <a id="2"></a>Scope

   1. <a id="2.1"></a>Apply these instructions when the project lead directs you to run a playtest round.

3. <a id="3"></a>Running the round

   1. <a id="3.1"></a>Read #380 from the top, or at least the last three rounds, so you know what has been tried and what is still open.

   2. <a id="3.2"></a>Post the round's plan on #380, per [DV-02](../SOPs/DV-02%20Running%20playtest%20rounds.md) §5.1.

   3. <a id="3.3"></a>Build the world from the current `main` and release the starter companies and the designs under test.

   4. <a id="3.4"></a>Play each newcomer persona as a separate player, using a separate agent where you can. Give each one only what a real newcomer has: the player's manual, `documents/lua-functions.md`, `examples/` and the game. Each writes its own Lua, releases it, watches it, and releases a better version when it fails. Record what each one tried, what broke, and how long it took to recover.

   5. <a id="3.5"></a>Collect the measures in [DV-02](../SOPs/DV-02%20Running%20playtest%20rounds.md) §5.3. Ask each persona for its ratings and its wish list at the end, in its own voice.

   6. <a id="3.6"></a>File an issue for each bug, per the "Machine instructions for identifying and posting issues" ([AD-01-M2](AD-01-M2%20Machine%20instructions%20for%20identifying%20and%20posting%20issues.md)).

   7. <a id="3.7"></a>Post the round's log on #380 with the "Playtest round comment template" ([DV-02-T1](DV-02-T1%20Playtest%20round%20comment%20template.md)).

   8. <a id="3.8"></a>Open a pull request with the round's economy playbook entry, per [DV-02](../SOPs/DV-02%20Running%20playtest%20rounds.md) §5.6.

   9. <a id="3.9"></a>Recommend, in the summary, the one change the round most strongly argues for, and whether it is worth a blog post.

4. <a id="4"></a>Provide a concise summary of activities performed and issues encountered when performing these instructions, including the round's headline result, the issues filed and the pull request opened.
