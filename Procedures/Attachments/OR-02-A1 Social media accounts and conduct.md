# OR-02-A1: Social media accounts and conduct

1. Accounts

   1. These are the project's public channels. Only the project lead, or someone the project lead names here, posts to them by hand. The one automatic poster is the Announce blog posts Action, per [OR-02](../SOPs/OR-02%20Engaging%20on%20social%20media.md) §2.2. Addresses not yet recorded here are filled in, by a pull request, when the accounts are set up; their owners go in the "Who owns what" table of `documents/sustainability-playbook.md`.

      | Channel | Address | Posted by | Used for |
      |---|---|---|---|
      | Bluesky | Not yet recorded: the handle in the `BLUESKY_HANDLE` Actions variable | The Action, and the project lead | Each new blog post, automatically; about one extra post a month (a screenshot, a leaderboard shout-out) |
      | Mastodon | Not yet recorded: an account on the instance in the `MASTODON_INSTANCE` Actions variable | The Action, and the project lead | The same as Bluesky |
      | Reddit | r/ProgrammingGames, r/lua, r/learnprogramming, r/CSEducation | The project lead, by hand | Big moments only, within each community's rules |
      | itch.io | Not yet set up: a free page pointing at the website | The project lead, by hand | Devlogs copied from the blog |
      | Hacker News | Show HN | The project lead, by hand | One launch post, when the game is ready for a crowd |
      | Ko-fi | The **Keep the Lights On** page, `/support` on the game's website, and the Ko-fi page it links to (not set up yet) | The project lead | The monthly supporter update, per [FR-01](../SOPs/FR-01%20Raising%20funds%20through%20Ko-fi.md) |
      | Blog | `/blog` on the game's website, with an RSS feed at `/blog/feed` | Merged pull requests | Teaching posts, per [OR-01](../SOPs/OR-01%20Writing%20and%20publishing%20blog%20posts.md) |
      | GitHub | [Darwin-River/Ex-Machinis](https://github.com/Darwin-River/Ex-Machinis) | Everyone | Issues, code and SOPs, open to all |

   2. X is not used: its API costs money.

   3. Channels the project may add, each by an issue and a pull request that adds it to the table above, per [OR-02](../SOPs/OR-02%20Engaging%20on%20social%20media.md) §5.8: a Discord channel (an RSS bot can post from `/blog/feed`, so it needs no code), a video channel for short drone demos, or a teacher community. Choose channels where teachers and people learning to code already are, and that the project can keep up with.

   4. The website loads Google Tag Manager. `admin/analytics.md` describes tagging the links in posts made by hand (Ko-fi, Reddit, Discord) so their visits can be counted. The Action's links are not tagged.

2. Voice

   1. Friendly, curious and plain. Write as a teacher who loves the game, not as an advertiser.

   2. Accurate. Every number, function name and claim matches the current game. If unsure, leave it out.

   3. Encouraging about failure. Ex Machinis is about break, learn, repeat: celebrate a clever fix as much as a win.

   4. Inclusive. Write for people who have never programmed as much as for those who have.

3. Conduct

   1. Keep students safe. Never post a student's name, photo, school, username or work without written permission from their school and, for a student under 18, a parent or guardian. Never message a student directly; talk to teachers and schools.

   2. Never ask for or collect personal information on social media.

   3. Never promise a feature or a date that has not been agreed in an issue.

   4. Never post anything that suggests supporters get a gameplay advantage or a reward; the game is free and fair for everyone, per [FR-01](../SOPs/FR-01%20Raising%20funds%20through%20Ko-fi.md) §4.2. Say "support" or "chip in", not "donate".

   5. Credit others' work, and ask before sharing a player's drone or code.

   6. Be honest about outages and bugs: say what broke, that it is being fixed, and link the issue.

   7. Do not argue. Answer a fair criticism with thanks and an issue; leave abuse unanswered and block or report it, as the project's `CODE_OF_CONDUCT.md` allows.

   8. Say when a post was drafted with AI help if a channel's rules require it.
