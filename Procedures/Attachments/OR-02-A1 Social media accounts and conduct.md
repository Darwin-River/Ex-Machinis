# OR-02-A1: Social media accounts and conduct

1. <a id="1"></a>Accounts

   1. <a id="1.1"></a>These are the project's public channels. Only the project lead, or someone the project lead names here, posts to them.

      | Channel | Address | Used for |
      |---|---|---|
      | X (Twitter) | [@exmachinis](https://twitter.com/exmachinis) | Short news, snippets, screenshots, links to posts |
      | Patreon | [patreon.com/exmachinis](https://www.patreon.com/exmachinis) | Patron updates and fundraising, per [FR-01](../SOPs/FR-01%20Raising%20funds%20through%20Patreon.md) |
      | Blog | `/blog` on the game's website | Teaching posts, per [OR-01](../SOPs/OR-01%20Writing%20and%20publishing%20blog%20posts.md) |
      | GitHub | [Darwin-River/Ex-Machinis](https://github.com/Darwin-River/Ex-Machinis) | Issues, code and SOPs, open to all |

   2. <a id="1.2"></a>Channels the project may add, each by an issue and a pull request that adds it to the table above: a video channel for short drone demos, a teacher community or forum, and communities for people learning to program. Choose channels where teachers and teenagers already are, and that the project can keep up with.

   3. <a id="1.3"></a>`admin/analytics.md` describes tagging links for Google Analytics. The website does not currently load analytics, so links are posted untagged unless the project lead restores it.

2. <a id="2"></a>Voice

   1. <a id="2.1"></a>Friendly, curious and plain. Write as a teacher who loves the game, not as an advertiser.

   2. <a id="2.2"></a>Accurate. Every number, function name and claim matches the current game. If unsure, leave it out.

   3. <a id="2.3"></a>Encouraging about failure. Ex Machinis is about break, learn, repeat: celebrate a clever fix as much as a win.

   4. <a id="2.4"></a>Inclusive. Write for people who have never programmed as much as for those who have.

3. <a id="3"></a>Conduct

   1. <a id="3.1"></a>Keep students safe. Never post a student's name, photo, school, username or work without written permission from their school and, for a student under 18, a parent or guardian. Never message a student directly; talk to teachers and schools.

   2. <a id="3.2"></a>Never ask for or collect personal information on social media.

   3. <a id="3.3"></a>Never promise a feature or a date that has not been agreed in an issue.

   4. <a id="3.4"></a>Never post anything that suggests patrons get a gameplay advantage; the game is free and fair for everyone, per [FR-01](../SOPs/FR-01%20Raising%20funds%20through%20Patreon.md) §4.2.

   5. <a id="3.5"></a>Credit others' work, and ask before sharing a player's drone or code.

   6. <a id="3.6"></a>Be honest about outages and bugs: say what broke, that it is being fixed, and link the issue.

   7. <a id="3.7"></a>Do not argue. Answer a fair criticism with thanks and an issue; leave abuse unanswered and block or report it.

   8. <a id="3.8"></a>Say when a post was drafted with AI help if a channel's rules require it.
