# QA-01-M1: Machine instructions for proofreading SOPs

1. <a id="1"></a>Always review and follow the most recent version of these instructions.

2. <a id="2"></a>Bring the document into the format of the SOP template ([QA-01-T1](QA-01-T1%20SOP%20template.md)), or of the machine instructions template ([QA-01-T2](QA-01-T2%20Machine%20instructions%20template.md)) for machine instructions, using the same section headings and numbering.

3. <a id="3"></a>Arrange the entries in the References and Attachments sections in alphabetical order by ID.

4. <a id="4"></a>Write every citation of an SOP or attachment ID as a Markdown link to that document's file, using a path relative to this document, per [QA-01](../SOPs/QA-01%20Writing%20and%20maintaining%20Ex%20Machinis%20standard%20operating%20procedures.md) §5.9.

5. <a id="5"></a>Run `python3 Procedures/Tools/update_anchors.py` on the document to refresh its item anchors, per [QA-01](../SOPs/QA-01%20Writing%20and%20maintaining%20Ex%20Machinis%20standard%20operating%20procedures.md) §5.10.

6. <a id="6"></a>Do not change the substance of any procedure. If a fix would need a judgment call, list it in the summary instead of editing the text.

7. <a id="7"></a>Provide a concise summary of activities performed and issues encountered when performing these instructions.
